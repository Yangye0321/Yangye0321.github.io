快捷键管理工具

发表于 2026-10-18

按一个键，代替一串组合键：我写了个 Windows 快捷键替代工具

用键盘久了，总会遇到这种别扭事：某个操作藏在三层快捷键后面，或者一个常用功能压根没有顺手的键位。

比如我想给正在播放的歌点个「喜欢」，网易云给的是 Ctrl+Alt+L；想在某些软件里按 Alt+Ctrl+小键盘0，得三根手指一起上。手指在键盘上找组合键的时间，足够打断一次专注。

于是我写了个小工具：自定义「触发键 → 输出组合键」的规则，按一个键就代替一串组合键。

它做什么

两个我自己天天用的场景：

按一下 实际发出 效果
小键盘 . Alt+Ctrl+小键盘0 在特定软件里触发组合键
F8 Ctrl+Alt+L 给网易云当前歌曲点「喜欢」

规则可以限定生效范围：只在白名单里的程序生效（比如只有网易云里 F8 才是点喜欢，别的程序里 F8 该干嘛干嘛），也可以设成全局。

替代模式由一个开关热键控制（默认 F12）：按一下进入替代模式，再按一下回到正常输入——这样你的键位不会一直被改掉。

几个真正难缠的问题

功能本身不复杂：装一个底层键盘钩子（WH_KEYBOARD_LL），命中规则就吞掉按键，再用 SendInput 把组合键注入回去。难的是那些「看起来能用、过一会儿就失效」的坑。

1. 钩子会被系统静默摘掉

Windows 对低层钩子回调有时限（约 300ms）。一旦超时，系统会把钩子从链上移除——不报错、不通知，句柄也不会变成 NULL。于是程序看着一切正常，实际一个键都收不到。

我最初在回调里同步写日志文件，就踩了这个坑。后来把日志改成后台线程异步写，并加了一个「看门狗」：如果已经收到过按键、但计数 25 秒不再增长，就判定钩子被摘，自动重装。

2. 低层钩子看不到管理员程序的按键

这是 UIPI（用户界面特权隔离）：普通权限的钩子收不到更高完整性级别程序的输入。表现就是「工具自己窗口里按键正常，切到别的程序全废」。

这不是 bug，是 Windows 的安全设计——否则任何普通程序都能窃听管理员窗口里的密码。解法只有一个：以管理员身份运行（工具现在会自动请求提权，另附一个不提权的启动脚本给介意 UAC 的人）。

3. 长按会反复触发

系统的长按会持续发「自动重复」的 KEYDOWN。如果按下即触发，按住一秒就能把组合键注入十几次。

最后我把开关热键和触发键都改成 「按下武装、松开才动作」：按下只记录，松开才真正执行。这样无论按多久、系统补发多少个事件，一次物理按压都只算一次。

4. 状态被自己覆盖

曾经出现过「按了 F12 却没切换模式」：模式存在引擎的独立属性里，而配置文件另存一份；界面只要保存一次配置，就用文件里的旧值把运行状态覆盖回去了。改成配置单一数据源后解决。

技术上是什么

  • Python + tkinter，纯标准库，零第三方依赖；
  • 单文件约 3400 行，包含配置、键名表、钩子、注入、规则引擎和界面；
  • 73 项单元测试，GitHub Actions 在 Windows 上跑 Python 3.9 / 3.11 / 3.13；
  • 内置诊断：--diag（15 秒实机诊断）、--watch（持续监听）、--keys（显示真实键码），外加一份记录钩子状态的心跳日志；
  • 可以打包成带 Python 的便携版，拷到别的电脑双击就能用。

怎么用

第一次启动会生成配置文件，带两条默认关闭的示例规则。在界面里点「录制」，按下你的触发键和输出组合，就能用了。

限制

  • 只支持 Windows 10/11；低层钩子意味着某些用 RawInput 或反作弊驱动的游戏可能绕过它；
  • 触发键只能是单个按键，输出组合最多 4 个键；
  • 它会申请管理员权限，并且未签名——所以启动时的 UAC 提示是预期行为，不是病毒；
  • 工具本身不联网、不上传任何数据，按键日志只写在本地。

最后

这类小工具的价值不在技术复杂度，而在「每天少按几次组合键」。真正花时间的也不是写功能，而是把那些只在特定条件下才暴露的竞态和系统限制一个个找出来。

代码开源在 github.com/Yangye0321/kuaijiejian，MIT 协议。如果你也有「这个功能为什么没有快捷键」的烦恼，欢迎试试，或者直接改一份自己用。

第二个实验是大数乘法，运用分治法思想。大数的位数为 2n，递归出口是当两个乘数足够小时，
直接相乘。否则将大数 X、Y 分为 A、B、C、D：

X = A × 10^n + B
Y = C × 10^n + D

可用公式：

X × Y = AC × 10^2n + (AB + CD) × 10^n + BD （四次乘法）

或变形公式：

X × Y = AC × 10^2n + ((A+B)(C+D) - AC - BD) × 10^n + BD （三次乘法）
