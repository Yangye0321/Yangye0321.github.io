第二周学习记录

发表于 2026-09-19

本周开始尝试着接触了ai智能体，从购买api，在vscode中安装了cline这个智能体插件到第一次使用智能体生成了一个连点器小工具，并且打包，推送到了仓库中。完成该连点器的过程中，解决了安装更高版本的python，转换虚拟环境，安装所需的库等等问题
此外我还借助agent管理了上学期的数据结构课设，课设的内容是基于哈希存储的通讯录，我让agent帮我编写了readme文件，整理项目并且推送到了仓库。
deepseek的高峰时段是工作日的上午 9:00 - 12:00 下午 14:00 - 18:00。我现在好像习惯于在晚上去学习这些东西了。
感觉慢慢会的东西就多起来了。
以下为deepseek的总结

本周学习总结（2026.09.13 - 2026.09.19）

一、AI 入口探索

  • GitHub Models 已退役，学生包不再提供免费大模型 API。
  • 转向 Google Gemini，用 AI Studio 获取免费 Key，配代理跑通第一次 API 调用。
  • 解决 Python 版本（3.9 → 3.12）、虚拟环境、SSL 报错等环境问题。

二、确定长期方案

  • 充值 DeepSeek API（10 元），了解高峰/空闲时段计费规则。
  • 了解硅基流动的定位（模型推理平台，不是中转站），领取认证奖励券。
  • 理清 API 与 Agent 的关系：API 是“大脑”，Agent 是“手脚”。

三、Agent 实践

  • 在 VS Code 里配好 Cline + DeepSeek API，跑通第一个自主任务（读代码、生成文档、整理目录）。
  • 体验 JetBrains ACP 智能体集成，确认 IDEA 的 Cline 暂不支持自定义 API，回到 VS Code。
  • 了解多 Agent 协作与当前主流开发模式（规格驱动、验证驱动）。

四、第一个真实项目：连点器

  • 技术路线：Python + PyAutoGUI + Tkinter。
  • 在 VS Code 中创建项目、配置 Python 3.12 虚拟环境、安装依赖。
  • 让 Cline 生成第一版代码，并尝试打包成 exe。
  • 解决中文乱码、文件编码（UTF-8）等问题。

五、当前状态

  • 拥有可用的 Agent 环境（Cline + DeepSeek）。
  • 有一个正在推进的小项目（连点器）。
  • 建立了对 API 调用、Agent 协作的基本认知。
