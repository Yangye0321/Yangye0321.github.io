我的第一篇博客

从大一开始我就想着要弄一个我自己的个人博客，我想过去学html+css+javascript这三剑客，但是半途而废了，而今成功搭建起这个博客是借助了deepseek的帮助，通过现有的框架直接做出一个能发布文章的简易个人博客。
在此埋下伏笔，希望未来能有自己的一个成熟的博客网站，能发一些有趣的东西。
既然是记录学习的，就简单说一下这周做了什么，通过deepseek，我了解了Java-Spring这个框架，并且做了后端用户管理api的接口，使用了MySql数据库使得数据能够长期存储，并且将该项目push到了我的GitHub仓库上。不过我认为我的学习程度还是有限，我认为我需要更多的了解该框架。

以下是deepseek为我总结的

本周完成

  • 完成用户管理 API 的 CRUD 接口
  • 集成 MySQL 数据库
  • 添加全局异常处理和数据校验
  • 将项目推送到 GitHub

遇到的问题

  • 启动时报错 Unknown database ‘test’，通过命令行创建数据库解决
  • 添加 @Valid 依赖时找不到版本，去掉版本号后由 Spring Boot 父工程自动管理

下周计划

  • 给项目添加分页查询
  • 复习 Java 八股
